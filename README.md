# The Dining Room — Villamartin (Sample Website)

Sample one-page restaurant website for **The Dining Room, Villamartin Plaza, Orihuela Costa, Spain** — built as a demo for the owner, before the final WordPress/Shopify decision.

## Files
- `index.html` — the whole site in one file: pure HTML/CSS/JS, no frameworks, mobile-first (same pattern as the Fames restaurant site).

## What is on the site
- **SAMPLE banner** — "SAMPLE WEBSITE — menu prices are samples, to be confirmed by the owner" (top bar, menu section and footer).
- **EN/ES language toggle** — the full site (headings, buttons, offers, booking form) switches between English and Spanish. Dish names stay the same; dish descriptions also translate.
- **Hero** — "India Meets Mexico in Villamartin Plaza", "Where Taste Meets Tradition", ratings (Google 4.6, TheFork 9.6/10, Tripadvisor 4.4).
- **About** — since 2021, family-friendly, kids menu, set menu, open till 1AM.
- **Menu** — 7 categories, 50 dishes: Indian Curries, Tandoori & Grill, Mexican, Starters, Breads & Rice, Kids, Desserts & Drinks. With category tabs, live search and a **Vegetarian only** filter. Signature dishes included: Signature Balti Curry, Chicken Tikka Masala, Tandoori Mixed Grill / Sizzling Tandoori, Chicken Fajita Wraps, Burritos, Quesadillas, Peshwari Naan, Chicken Pakora, Mixed Grill starter.
- **Offers** — Early Bird Set Menu, Free Delivery, Family Night, Friday Fusion.
- **Gallery** — 8 sample food/interior photos.
- **Reviews** — Google 4.6★, Tripadvisor 4.4★ (57 reviews), TheFork 9.6/10 (282 reviews); quotes are themes paraphrased from real Tripadvisor reviews, not invented word-for-word quotes.
- **Visit Us** — Av. de las Brisas 6, Villamartin Plaza, 03189 Villamartin, Orihuela Costa, Spain. Hours: Daily 4PM–1AM. Phone 865 942 367, WhatsApp 641 90 08 45, Facebook page link, Google Maps embed + Get Directions.
- **Book a Table form** — name/date/time/guests/phone/notes; on submit it opens WhatsApp (`wa.me/34641900845`) with the booking details pre-filled.
- **Sticky mobile bar** — Call / WhatsApp Order / Book Table (mobile only).
- **SEO** — title, description, keywords, Open Graph tags for "Indian restaurant Villamartin" / "Mexican restaurant Orihuela Costa".

## Real facts used
- Address, phones, hours, free delivery in Orihuela Costa, family & kids menu, set menu / early bird, ratings above, Facebook 1,991 followers — all from the restaurant's public Facebook/Tripadvisor/TheFork listings, checked 23 Nov 2026.
- **Menu prices are SAMPLES in Euros (marked with `*`)** — the owner must confirm real prices before launch. Do not publish as real prices.

## Photos — placeholders
Food/interior photos are **Unsplash hotlinks (placeholders)**, not the restaurant's own photos. The site says so in the Gallery and in the footer. Replace them with the owner's real food photos before launch — the README and the site both say this. No photo is claimed to be the restaurant's own.

## How to view
Open `index.html` in any browser, or serve it:
```
cd the-dining-room-website
python3 -m http.server 8000
# then open http://localhost:8000/
```
